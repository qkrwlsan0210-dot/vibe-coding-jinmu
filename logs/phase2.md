# Phase 2 — 기능 단위 재구축 기록

## 기능 순서 (AI 제안, 진무 승인)
1. 플랜 설정 화면 2. 오늘 화면 3. 기상 체크·재계산 4. 유지 단계·마무리

## 기능 1: 플랜 설정 화면 — 커밋 `65a6416`
- 요청 원문: `페이즈 2이동` → AI가 기능 순서·기능 1 계획 제시
- 진무 결정: 입력칸 예시값 채워두기(13:00 / 08:00 / 30분 / 8시간) · 현재=목표 저장 허용 · 계획 승인
- 구현: 입력 4개(현재·목표 기상, 이동 폭 1~180분, 수면 시간 3~14시간), 입력칸 아래 오류 표시, localStorage `sleepPlan` 저장, 첫 실행 시 설정 화면 → 저장 후 오늘 화면(자리만), 플랜 수정·취소
- 확인한 것 (헤드리스 Chromium, 360px, Asia/Seoul): 첫 실행 흐름, 기본값, 잘못된 입력 9가지(0·181·2.5·빈칸 분, 2시간·14시간1분·60분·빈칸 시간, 빈 기상 시각) 저장 차단+메시지, 경계값(180분·14시간) 저장, 현재=목표 저장, 수정 시 저장값 불러오기, 취소 시 저장값 유지, 새로고침 후 오늘 화면. 콘솔 오류 없음.
- 확인하지 않은 것: 실제 휴대폰(시각 입력 UI는 기기마다 다름), 오늘 화면 내용(기능 2)
